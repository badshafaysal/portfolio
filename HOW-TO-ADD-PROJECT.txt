========================================
  HOW TO ADD A NEW PROJECT (no coding)
========================================

1. Open your website → https://YOUR-SITE.pages.dev/admin/
2. Login with GitHub (first time only)
3. Projects → New Project
4. Fill in:
      - Title
      - Short description (homepage card)
      - Summary (optional, longer text on project page)
      - Categories (tick one or more)
      - Tags (optional)
      - Cover image
      - Gallery photos (add as many as you want)
      - Location / Client / Year / Scope (optional facts)
      - Order number (1 = first)
      - Full notes (optional markdown)
5. Publish
6. Wait 1–2 minutes → refresh site

Each project gets its own page with gallery, facts, prev/next, and share buttons.

To edit or delete: Admin → click project → change or delete → Publish.
